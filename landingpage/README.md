# Lumea Landingpage

Leeres React-Projekt mit TypeScript und Vite.

## Lokal starten

```sh
npm install
npm run dev
```

## Prüfen und bauen

```sh
npm run lint
npm run build
npm run preview
```

Der Produktionsbuild wird in `dist/` erstellt.

## Struktur

- `src/App.tsx`: Einstieg für die Landingpage, aktuell leer
- `src/index.css`: globale Basisstyles
- `src/assets/`: importierte Bilder und andere Assets
- `public/`: statische Dateien

Design, Inhalte, Bestellstrecke und Tracking werden später ergänzt.
